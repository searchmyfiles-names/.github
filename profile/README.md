# SearchMyFiles - Find a File on a Disk You May Search

SearchMyFiles is a search form for this PC. You set a name or a folder and read the list. Opening a result is still opening a file, so you need the right to read it.

---

## Product Snapshot

Start with a directory and a name you remember. Dates can narrow a shoot or a download from a day you know. Text search reads files it is able to read. It will be slower, and it should stay inside a folder you own. Searching the whole system for a common word returns noise and private files that are not part of your task.

The result list can contain paths you should not browse. If a row is outside the folder you meant, ignore it. Do not export a list of another user's documents. Stop the search when you have the file.

## Live Production

Use it when Explorer search is too blunt and you know the folder. Find one project file, open it, and close the tool. A search of C:\Users for a private word on a shared PC will show other people. Do not do that to look through their files.

If you need a list for yourself, save it in a private folder and delete it when the hunt is over. SearchMyFiles does not delete what it finds unless you delete the file yourself in Explorer, which you should do only for files you may delete.

---

## Widen by One Step

If the name is not in the project folder, add the parent you also own, not the whole disk. Stop at the first real hit. A longer search is how other people's paths enter the list.

---

## Setup Path

Prerequisites: A folder you may search, and a name or a date you actually remember.

1. Open SearchMyFiles and set that folder, not every drive.
2. Enter a specific name.
3. Run the search and open the file you expected.
4. Stop. Do not wander into other users' paths.
5. Delete a saved result when you no longer need it.

## Who Benefits

SearchMyFiles fits a file you misplaced inside your own folders. It does not fit a sweep of other users, a fishing search of the whole PC, or a published list of private paths.

---

## Fixes

Nothing found: the name is different, or the folder is wrong. Widen one step, not to the whole disk at once. Too many hits: add a date or a longer name. A path is not yours: do not open it.
